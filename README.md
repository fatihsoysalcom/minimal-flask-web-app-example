# Minimal Flask Web App Example

This example provides a minimal Flask web application, demonstrating basic routing, HTML responses, and JSON API endpoints. It serves as a simple illustration of how a Python web framework functions, a core concept discussed in the accompanying article comparing Django, Flask, and FastAPI for future web projects.

## Language

`python`

## How to Run

1. Ensure Python 3 is installed.
2. Install Flask: `pip install Flask`
3. Run the application: `python main.py`
4. Open your browser to `http://127.0.0.1:5000/`, `http://127.0.0.1:5000/api/hello`, or `http://127.0.0.1:5000/greet/yourname`
